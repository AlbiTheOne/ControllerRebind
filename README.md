# Controller Rebind

Free controller button layout for GTA IV: every button and both triggers can do what another one does, set up in an in-game menu.

**Download (ready to use):** https://www.nexusmods.com/gta4/mods/1753

Target: GTA IV: The Complete Edition 1.2.0.59 + [FusionFix](https://www.nexusmods.com/gta4/mods/716) (32-bit ASI plugin).

## Building

See [BUILD.txt](BUILD.txt) for the build command (zig or MSVC, 32-bit Windows DLL renamed to .asi), how the graphics are made and how the mod works.
